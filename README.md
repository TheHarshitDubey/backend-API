🛡️ AI Scam Shield

AI Scam Shield is a mobile application that detects potential scam messages using AI and helps users respond safely.

🚀 Features

- 🔍 AI Scam Detection
  Analyze suspicious messages using AI to determine if they are scams.

- 📸 OCR Text Extraction
  Extract text from screenshots using Google ML Kit and analyze it instantly.

- 🤖 AI Generated Safe Reply
  Generate a safe response that protects user privacy and avoids sharing sensitive information.

- 📊 Analytics Dashboard
  View statistics such as:
  
  - Total scans
  - Scam messages detected
  - Safe messages
  - Risk percentage

- 🕒 Scan History
  Track previously analyzed messages.
